# 🎓 Student Management System

A Python-based Student Management System designed to efficiently manage student academic records, attendance, grades, CGPA, rank lists, and progress cards through a simple menu-driven interface.

---

## 📌 Overview

The Student Management System automates the process of maintaining student records and academic performance. It allows users to store student information, enter subject-wise marks, calculate grades and CGPA, generate rank lists, identify toppers, monitor attendance, and generate progress cards.

This project demonstrates the practical application of Python programming concepts such as functions, loops, conditional statements, dictionaries, lists, sorting algorithms, and data management techniques.

---

## ✨ Features

### 👨‍🎓 Student Management

* Add new student records
* Display all student records
* Search students by name
* Remove student records

### 📚 Academic Management

* Subject-wise marks entry for N subjects
* Automatic total marks calculation
* Percentage calculation
* Grade assignment
* CGPA calculation
* Pass/Fail recognition

### 🏆 Performance Analysis

* Rank list generation
* Class topper identification
* Academic performance tracking
* Student progress card generation

### 📅 Attendance Monitoring

* Attendance percentage calculation
* Low attendance warning system
* Attendance tracking and reporting

## 📊 Functional Modules

### 1. Add Student

Stores student details including:

* Name
* Date of Birth

### 2. Grade & CGPA Calculation

Automatically calculates:

* CGPA
* Attendance
* Result

---

## 📖 Algorithm

1. Start the program.
2. Create an empty student database.
3. Display the main menu.
4. Accept user choice.
5. Perform the selected operation:

   * Add Student
   * Display Students
   * Search Student
   * Remove Student
   * Generate Progress Card
   * Generate Rank List
   * Identify Topper
6. Repeat until the user chooses Exit.
7. Stop the program.
